## Contributing

Contributions are welcome! Please read the [contribution guidelines](CONTRIBUTING.md) first.

### Criteria for inclusion:

- ✅ **Open Source**: Must have publicly available source code
- ✅ **AI/ML Focus**: Clear artificial intelligence or machine learning functionality
- ✅ **Active Development**: Regular commits and maintenance (updated within 12 months)
- ✅ **Quality Threshold**: Minimum 50 GitHub stars or demonstrated community adoption
- ✅ **Functional**: Working implementation, not just concepts or abandoned projects
- ✅ **Well Documented**: Clear README and usage instructions

### How to contribute:

1. Fork this repository
2. Follow the format: `**[Tool Name](link)** ⭐ stars - Brief description`
3. Ensure the tool meets our inclusion criteria
4. Submit a pull request with clear description
